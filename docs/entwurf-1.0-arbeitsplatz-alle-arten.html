Ein Arbeitsplatz für jede Art von Programm

Entwurf zum Konzept, mit Beispielen gefüllt. Links siehst du die Zentrale, in der Mitte die offenen Punkte des Features und den Chat, rechts drei Ansichten: Vorschau (was du baust), Code live (welche Dateien die Werkstatt gerade ändert, Zeile für Zeile) und Verlauf. Das gilt für jede Art. Klick auf einen Punkt: Der Chat bezieht sich darauf und „Weiterarbeiten“ gibt genau diesen Punkt als Auftrag. Beim Thermax Planer läuft im Beispiel gerade ein Auftrag. Alle Inhalte sind ausgedacht.
